## Quizzy Project

This project is part of the Design Patterns course in my 3rd year of the Computer Science degree.

Main Functions of the Project: Creating "Quizzes," loading them into and from a CSV file, and completing the test through two options:

**1. GUI Test:**
Multiple-choice questions (4 options) using default GUI methods for Java in IntelliJ.

**2. Terminal Test:**
Open-ended questions using terminal options.

# Design Patterns
1. Singleton
2. Data Access Object (DAO)
3. Builder Pattern
4. JUnit Testing
